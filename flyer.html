How to generate the Video:

  1. Save your Canva video as forro_video.mp4 and put it in the assets/ folder. (The page uses an animated Brazilian gradient fallback if missing).
  2. Optionally save a song loop as forro_music.mp3 in assets/.
  3. Click Start Recording Mode.
  4. Use OBS Studio, Chrome screen recorder, or Loom to record the window/screen.
  5. Press ESC to end recording, then edit or post to Instagram Reels!
